# Bản lưu trước khi tối ưu hướng dẫn

Ba file sau là bản sao nguyên byte của nội dung làm việc ngày 2026-09-24, gồm cả thay đổi chưa commit. Chúng là tư liệu lịch sử, không phải hướng dẫn hiện hành; các nhãn “current/latest”, lệnh, hash và đường dẫn có thể lỗi thời.

| Bản lưu | Nguồn gốc / gốc đường dẫn bên trong | Mục đích tra cứu |
|---|---|---|
| [root.md](root.md) | `CLAUDE.md`, repo root | Quyết định bố trí, ghi chú các release cũ |
| [client.md](client.md) | `client/workspace/CLAUDE.md`, `client/workspace/` | Legacy build, x3, RMS, repoint, bảng phiên bản và changelog |
| [server.md](server.md) | `server/CLAUDE.md`, `server/` | Danh sách bản vá 23/08/2026, admin và vận hành cũ |

Không đọc toàn bộ mặc định, không import tự động. Dùng `rg -n '^#|<từ khóa>' <file>` để tìm mục rồi chỉ đọc đoạn liên quan. Link/đường dẫn trong bản sao vẫn tính từ vị trí nguồn gốc nêu trên.

Hướng dẫn hiện hành: [gốc](../../../CLAUDE.md), [client](../../../client/workspace/CLAUDE.md), [server](../../../server/CLAUDE.md). Release/hash hiện hành và các điểm chưa xác minh ở [RELEASES.md](../../../client/workspace/docs/RELEASES.md).
