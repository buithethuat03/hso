Chương 02: Bảng Số Liệu Toán Học Chiến Đấu & Danh Mục Option CSDL

Công thức toán học chính xác 100% trích xuất từ Body.java và MapService.java, kèm bảng tra cứu 60+ mã Option từ bảng itemoption trong CSDL MySQL và ví dụ tính toán từng bước.

2. Công Thức Tính Toán Chi Tiết (client/Body.java)

Công Thức Sát Thương Vật Lý

// 1. Sát thương thô:
Dame_VatLy_Tho = (Str * 10) + total_item_param(0);

// 2. Hệ số % gia tăng (get_percent_damePhysical):
Percent_Tang = total_item_param(7) + (Str * 20); // Đối với Chiến Binh / Sát Thủ
// Với Pháp Sư / Xạ Thủ: + (Str * 20 + Int * 18)

// 3. Sát thương vật lý tổng:
Dame_VatLy_Tong = Dame_VatLy_Tho + (Dame_VatLy_Tho * Percent_Tang / 10000);

Công Thức Sát Thương Nguyên Tố

// Type: 1-Băng, 2-Lửa, 3-Độc, 4-Sét
Dame_NT_Tho = (Int * 10) + total_item_param(type);

Percent_NT_Tang = total_item_param(7 + type) + (Int * 20);

Dame_NT_Tong = Dame_NT_Tho + (Dame_NT_Tho * Percent_NT_Tang / 10000);

Công Thức Tính Máu (HP) & Mana (MP)

// Máu tối đa:
Max_HP = (Vit * 10) + total_item_param(25);
Max_HP_Tong = Max_HP + (Max_HP * total_item_param(27) / 10000);

// Mana tối đa:
Max_MP = (Int * 10) + total_item_param(26);
Max_MP_Tong = Max_MP + (Max_MP * total_item_param(28) / 10000);

Hệ Số Nhân Thú Cưỡi & Uy Lực Cánh

• Thú cưỡi Cấp 3: Sát thương * 1.2 (+20%)
• Thú cưỡi Cấp 5: Sát thương * 1.4 (+40%)
• Ngựa Chiến 114: Sát thương * 1.15 (+15%)
• Ngựa Chiến 116: Sát thương * 1.35 (+35%)
• Power Wing (Eff -120): +2000 điểm Option 7..11, 15

3. Ví Dụ Tính Toán Minh Họa Cụ Thể (Step-by-Step Example)

📝 Ví Dụ Thực Tế: Nhân Vật Chiến Binh Cấp 100

Thông số nhân vật:

  • Điểm Sức Mạnh (Str) = 500, Thể Lực (Vit) = 200, Tinh Thần (Int) = 50.
  • Đang mặc Trọng Kiếm +15 có dòng Sát thương vật lý gốc = 1000. Tại cấp +15: (280 * 1000)/100 = 2800 sát thương.
  • Áo giáp và phụ kiện có tổng +20% Sát thương vật lý (Option 7 = 2000).
  • Cưỡi Thú cưỡi Cấp 5 (Hệ số nhân 1.4).

Các bước tính toán của Server:

  1. Dame_VatLy_Tho = (500 * 10) + 2800 = 7.800 điểm.
  2. Percent_Tang = 2000 + (500 * 20) = 12.000 (tương đương +120%).
  3. Dame_VatLy_Tong = 7.800 + (7.800 * 120 / 100) = 17.160 điểm.
  4. Khuếch đại Thú cưỡi Cấp 5: 17.160 * 1.4 = 24.024 sát thương.
  5. Nếu xuất hiện đòn đánh Chí Mạng (Crit): Sát thương gây ra là 24.024 * 2 = 48.048 damage lên quái vật!
