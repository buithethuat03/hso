Chương 01: Hạ Tầng Mạng, Vòng Đời & Packet Protocol

Phân tích toàn diện luồng kết nối TCP, vòng đời Server, cơ chế xử lý đa luồng, giải mã nhị phân nhị phân (Binary Protocol) và đường ống lưu trữ CSDL MySQL.

1. Vòng Đời & Khởi Động Server (Server Lifecycle)

Hệ thống khởi chạy từ core/Start.java và điều phối bởi core/ServerManager.java:

1. Nạp Cấu Hình & Database

Đọc file hso.conf (Cổng port, MySQL host, user, pass, database name). Khởi tạo kết nối SQL.gI().init().

2. Nạp Cache Dữ Liệu Tĩnh

Hàm Manager.gI().init() nạp toàn bộ Template: Item 3/4/7, Quái vật, Bản đồ, Kỹ năng, NPC, Thời trang vào RAM (HashMap / List).

3. Khởi Chạy Background Threads

Kích hoạt luồng SaveData (tự động lưu nhân vật), Timer các sự kiện định kỳ (Chiến trường, Boss TG, Đấu giá, Chiếm mỏ).

4. Mở Cổng Socket Lắng Nghe

Mở ServerSocket trên port đã định cấu hình. Mỗi kết nối mới sinh ra 1 đối tượng Session với 2 luồng đọc/ghi riêng biệt.

2. Đường Ống Mạng & Giao Thức Nhị Phân (Binary Packet Pipeline)

Mô hình truyền thông điệp giữa Client và Server sử dụng chuẩn nhị phân tùy biến (Big-Endian Data Streams):

// Cấu trúc một khung tin nhắn (Frame) trên đường truyền:
[Byte: Command ID] + [Int/Short: Data Length (nếu có)] + [Binary Payload: DataInputStream / DataOutputStream]
Thành Phần File Mã Nguồn Nhiệm Vụ & Chi Tiết Kỹ Thuật
Session io/Session.java Đại diện cho 1 socket client. Quản lý DataInputStream (luồng nhận), DataOutputStream (luồng gửi), hàng đợi tin nhắn gửi ra (Send Queue) và khóa đồng bộ.
Message io/Message.java Bao bọc ByteArrayOutputStream / DataOutputStream (ghi dữ liệu) hoặc ByteArrayInputStream / DataInputStream (đọc dữ liệu). Hỗ trợ đọc/ghi byte, short, int, long, UTF string, boolean.
MessageHandler client/MessageHandler.java Bộ điều hướng gói tin đầu vào (Incoming Packet Router). Phân luồng lệnh switch-case dựa theo Command ID từ client gửi lên.
Service core/Service.java Tập hợp các hàm trợ năng đóng gói Message gửi từ Server về Client (Send Notice, Send Chat, Send Dialog, Send Character Info...).

4. Mô Hình Xử Lý Đa Luồng & Timer (Threading Model)

⚠️ Điểm Cần Lưu Ý Khi Nâng Cấp Đa Luồng

Server sử dụng cơ chế khóa phân đoạn theo Map: synchronized (map) cho các thao tác chiến đấu, nhặt đồ và di chuyển. Điều này giúp ngăn chặn Race Condition giữa người chơi trong cùng một khu vực nhưng có thể gây giật lag cục bộ nếu có quá nhiều vòng lặp nặng trong khối synchronized.

  • Luồng Socket Listener (1 Thread): Chấp nhận kết nối mới và khởi tạo Session.
  • Luồng Đọc Gói Tin (1 Thread / Client): Vòng lặp liên tục đọc byte từ socket và chuyển cho MessageHandler.
  • Luồng Gửi Gói Tin (1 Thread / Client): Lấy Message từ hàng đợi List<Message> và ghi vào socket OutputStream.
  • Luồng Cập Nhật Map / Mob (Map Update Thread): Định kỳ 500ms - 1000ms hồi sinh quái vật, trừ thời gian tồn tại của vật phẩm rơi và giải phóng phó bản hết giờ.
  • Luồng Auto-Save (core/SaveData.java): Chạy nền định kỳ 5 phút lưu toàn bộ người chơi đang online vào MySQL để tránh mất dữ liệu khi máy chủ mất điện đột ngột.

5. Kiến Trúc Lưu Trữ Dữ Liệu (MySQL Storage Architecture)

Dữ liệu nhân vật được lưu trữ theo mô hình lai (Relational + JSON Serialization) trong bảng player:

-- Cấu trúc bảng player cốt lõi:
CREATE TABLE `player` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `user_id` int(11) NOT NULL,
  `name` varchar(30) NOT NULL,
  `clazz` tinyint(4) NOT NULL,           -- 0: Chiến Binh, 1: Sát Thủ, 2: Pháp Sư, 3: Xạ Thủ
  `level` smallint(6) NOT NULL,
  `exp` bigint(20) NOT NULL,
  `vang` bigint(20) NOT NULL,
  `ngoc` int(11) NOT NULL,
  `item3` text NOT NULL,                 -- JSON array chứa toàn bộ trang bị mặc và trong rương
  `item4` text NOT NULL,                 -- JSON array chứa dược phẩm, rương, phù
  `item7` text NOT NULL,                 -- JSON array chứa ngọc, đá nâng cấp, NLMD
  `skill` text NOT NULL,                 -- JSON array điểm kỹ năng đã cộng
  `tutien` varchar(100) DEFAULT '[0,0]', -- Cảnh giới tu tiên và điểm tích lũy
  `kinhmach` varchar(100) DEFAULT '[0,0]',-- Tầng kinh mạch và điểm khai thông
  `luyenthe` tinyint(4) DEFAULT 0,       -- Cấp độ luyện thể
  `nv_tinh_tu` varchar(100) DEFAULT '[0,0,0,0]', -- Tiến độ nhiệm vụ tinh tú
  PRIMARY KEY (`id`)
);
